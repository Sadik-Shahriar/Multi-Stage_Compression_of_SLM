## **Term Project Submission Guidelines** 

Instructor: Ahmed Abdal Shafi Rasel (ahmed.shafi@ewubd.edu) 

Please read and adhere strictly to the following instructions for your final term project submission. 

# **1 Formatting & Templates** 

-  **Standard Track (Default):** All groups are required to prepare their report using the official **ACM Conference Proceedings Primary Article Template** . 

   - Overleaf Template Link: ACM Conference Proceedings Template 

###  **Journal Track (Exception):** 

- Teams planning to submit their work to a journal must **consult the instructor via email** prior to submission. 

- Upon approval, these groups must initially prepare and submit their draft using the standard **arXiv LaTeX template** . 

# **2 Submission Artifacts & Requirements** 

Every group must submit the following items: 

**1. Compiled PDF Report:** The complete final report compiled directly from your LaTeX source into PDF format. 

**2. LaTeX Source Files (** `.zip` **):** A compressed archive containing all source files required to build your document, structured as follows: 

   -  Main source file ( `.tex` ) 

   -  Bibliography file ( `.bib` ) (use BibTeX for references, zotero recommended) 

   -  Figures directory ( `/figures` or `/images` ) 

   -  Any associated style ( `.sty` ) or class ( `.cls` ) files. 

### **3. GitHub Repository (Private):** 

-  Host all project source code, scripts, and documentation in a **private** GitHub repository. 

-  Add the instructor as a collaborator using the email: `ahmed.shafi@ewubd.edu` . 

-  Include a comprehensive `README.md` with clear instructions to run your code. 

### **4. Individual Contribution Percentage Submission:** 

-  **Each student must** submit their individual contribution percentage breakdown via the designated Google Sheet (not in the paper).
